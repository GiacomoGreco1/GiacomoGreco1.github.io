P/01 Android · Tablet

Scriba

Android-Tablet-App für Handschrift-Notizen und PDF-Annotation.

  • Kotlin
  • Jetpack Compose
  • androidx.ink
  • Motion Prediction
  • PdfRenderer
Problem
Mit dem Stift schreiben und PDFs annotieren – so direkt wie auf Papier, ohne Konto und ohne Cloud. Jede Millisekunde Verzögerung zwischen Stiftspitze und Linie stört.
Gelöst
  • Front-Buffer-Rendering für latenzfreie Stifteingabe: Der Strich wird am normalen Zeichenzyklus vorbei gezeichnet, Motion Prediction ergänzt die nächsten Millisekunden.
  • Eigene Formerkennung: Stift kurz halten, und aus dem krummen Kreis wird ein sauberer – ebenso Rechteck, Dreieck und Polygon. Rein geometrisch, per Kleinste-Quadrate-Fit.
  • Atomares Speichern (Temp-Datei, dann Rename) mit .bak-Backup in einem eigenen, versionierten Binärformat.
  • Undo/Redo für alle Operationen über Action-Objekte.
  • 100 % offline – die App fordert nicht einmal die INTERNET-Permission an.

Privates Repository – den Code zeige ich gern im Gespräch.

P/02 Android · Sleep-Timer

Blackouter

Sleep-Timer, der Medien pausiert (Twitch, YouTube, Spotify), zum Homescreen wechselt und das Display sperrt.

  • Flutter
  • Dart
  • Kotlin
  • MethodChannel
  • AlarmManager
  • Device Admin
Problem
Wer beim Streamen einschläft, lässt Display und Akku die ganze Nacht laufen. Der Timer muss zuverlässig auslösen – auch wenn Android die App längst in den Hintergrund geschoben hat.
Gelöst
  • Neustart statt Flickwerk: Der erste Versuch mit React Native scheiterte im Hintergrund. Umstieg auf AlarmManager (setExactAndAllowWhileIdle) und Device Admin (lockNow) – läuft jetzt auch bei geschlossener App.
  • Audio-Focus anfordern, um fremde Apps sauber zu pausieren.
  • Dot-Matrix-Ziffern per CustomPainter im Nothing-Design – dieselben Punkte wie oben im Namen.

Privates Repository – den Code zeige ich gern im Gespräch.

P/03 Android · Offline

FH6 Tempi

Offline-App für Rundenzeiten in Forza Horizon 6.

  • React 19
  • Vite
  • Capacitor
  • GitHub Actions
Problem
Eigene Rundenzeiten über viele Strecken und Autos festhalten und vergleichen – am Handy neben dem Controller, ohne Server und ohne Anmeldung.
Gelöst
  • APK aus der Cloud: GitHub Actions baut die App – ohne lokales Android-Setup.
  • Filter, Sortierung und persönliche Rekorde pro Strecke, grün markiert – vollständig offline auf dem Gerät.
  • JSON-Import/Export für Backup und Gerätewechsel.

Privates Repository – den Code zeige ich gern im Gespräch.

P/04 ESP32 · IHK-Abschlussprojekt

MTC-Ampel

Signalampel für die Fertigungsüberwachung: zeigt Schraubergebnisse direkt an der Station.

  • C++
  • ESP32
  • TCP
  • OpenProtocol
  • WLAN-AP
Problem
Ob eine Verschraubung in Ordnung war, soll der Werker sofort sehen und hören – ohne auf einen Bildschirm zu schauen.
Gelöst
  • Schraubergebnisse per TCP/OpenProtocol direkt auf dem Mikrocontroller empfangen und auswerten.
  • ESP32 als WLAN-Access-Point – läuft unabhängig vom Werksnetz.
  • OK/NOK über LEDs und Buzzer. IHK-Bewertung: 85 Punkte.

github.com/GiacomoGreco1/MTC-Ampel↗

P/05 ESP32 · IoT

Wetter-Station

IoT-Wetterstation mit ESP32 (WiFi LoRa 32 V3) und BME688-Sensor.

  • C++
  • ESP32
  • BME688
  • I²C
  • OLED
  • Fusion 360
Problem
Raumklima live messen und anzeigen – als fertiges Gerät auf dem Tisch, nicht als Breadboard mit Kabelsalat.
Gelöst
  • BME688 über I²C: Temperatur, Luftfeuchtigkeit, Luftdruck und Gaswiderstand.
  • Live-Anzeige auf dem OLED-Display.
  • Eigenes Gehäuse in Fusion 360 konstruiert und 3D-gedruckt.
